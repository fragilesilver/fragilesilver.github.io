muOS Andromeda Package Setup

How to install on your device

All muOS apps are packaged as standalone .muxapp archives bundling their own LÖVE runtime and dependencies.

01

Download .muxapp

Grab the latest .muxapp release package from GitHub Releases for your chosen app.

02

Transfer to SD Card

Copy the .muxapp file to the ARCHIVE/ directory on your SD1 or SD2 card.

03

Open Archive Manager

On your handheld device, go to Applications → Archive Manager and select the file.

04

Launch & Enjoy

Launch your newly installed app directly from Applications in muOS.

No terminal commands or root access required on device
