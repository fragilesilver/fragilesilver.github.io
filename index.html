Craftsmanship

Development Philosophy

Whether designing an alarm clock for a pocket Linux console or a live multiplayer ocean arena for students, I believe software should be intentional, fast, and delightful to interact with.

Lightweight & Bloat-Free

Crafting software that boots in milliseconds, conserves battery, and minimizes memory consumption across handheld and web platforms.

Tactile & Joyful Ergonomics

Prioritizing physical gamepad button contracts, clean layout letterboxing, and rewarding audio/visual interactions.

Independent & Self-Contained

Delivering standalone archives and robust data persistence that survives firmware updates and operating system reboots.

Pedagogy & Open Collaboration

Creating tools that demystify computer science concepts and sharing open code for retro gaming and educational communities.
