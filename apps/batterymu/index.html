RG35XX Pro, Plus, H, SP, 2024•H700

Telemetry Features

Live Charge & Voltage Gauge

Real-time percentage readout, microvolt-accurate voltage tracking, and instant charge/discharge state detection.

Cell Health Analysis

Compares design voltage against current full-charge capacity to calculate actual battery health percentage over time.

muOS Charge History Graph

Visualizes discharge curves and session time directly from muOS's built-in battery_usage tracker.

AXP2202 Sysfs Fallback

Reads pre-parsed muOS battery status with automated fallback to the raw AXP2202 PMIC sysfs interface across all H700 handhelds.

Universal H700 Sensor Implementation

Because all members of the Anbernic H700 family (RG35XX Pro, Plus, H, SP, and 2024) utilize the identical X-Powers AXP2202 Power Management IC, BatteryMu delivers consistent, calibrated telemetry regardless of which device or screen revision you play on.
