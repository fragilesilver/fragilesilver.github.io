Handheld Setup Guide

How to Install .muxapp Packages

A quick, beginner-friendly walkthrough on installing ClockMu, JarMu, BatteryMu, SwapMu, and ScrapMu on your Anbernic handheld running muOS Andromeda.

muOS Andromeda 2606.0+•Allwinner H700
1

Download the .muxapp Release Package

Navigate to the Releases page of your desired app on GitHub and download the latest compiled .muxapp archive file (e.g. ClockMu-1.0.0.muxapp, SwapMu-1.0.0.muxapp).

2

Transfer to your SD Card's ARCHIVE/ Folder

Connect your SD card (either SD1 or SD2) to your computer using a card reader, USB transfer, or over Wi-Fi/SFTP. Place the downloaded .muxapp file directly into the ARCHIVE/ directory located at the root of your SD card.

3

Open Archive Manager on Your Handheld

Boot your handheld device into muOS Andromeda. On the main muOS home menu, navigate to Applications, then scroll down and open Archive Manager.

4

Extract and Install the App

In Archive Manager, select the .muxapp file from the list and press [A]. muOS will automatically unpack the application binaries, icons, and launcher scripts into their proper system directories.

5

Launch from Applications Menu

Return to the muOS Applications menu. Your newly installed application will now be visible with its custom icon. Press [A] to launch and enjoy!

Frequently Asked Questions

Will updating an app erase my alarms, game filters, or battery history?

No! All fragilesilver apps use persistent storage directories (e.g., save/ via exported environment variables like $CLOCKMU_DATA or $JARMU_DATA). Your settings and history survive updates and reboots.

Do I need SSH, a terminal, or custom scripts to install these?

Not at all. The .muxapp format is native to muOS and is handled entirely through the built-in muOS Archive Manager interface.

Which handheld devices are supported?

All Allwinner H700 devices running muOS Andromeda: Anbernic RG35XX Pro, RG35XX Plus, RG35XX H, RG35XX SP, and the RG35XX (2024 revision).

Can I remove the .muxapp file after installing?

Yes. Once the Archive Manager has successfully installed the application, you can safely delete the original .muxapp file from your ARCHIVE/ folder to save storage.
